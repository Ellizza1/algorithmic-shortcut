# ⚡ Академическая Дистилляция: Алгоритмы Графов в Лабиринтах

Шпаргалка и архитектурный справочник по алгоритмам генерации остовных деревьев и поиска кратчайших путей на решетчатых графах (Grid Graphs).

---

## 1. 📐 Математическая модель лабиринта

Лабиринт размера $W \times H$ формализуется как **остовное дерево (Spanning Tree)** на планарном решетчатом графе $G = (V, E)$:
* **Вершины ($V$):** Ячейки $(x, y)$, где $x \in [0, W-1]$, $y \in [0, H-1]$. Всего $|V| = W \times H$.
* **Ребра ($E$):** Стены между ортогонально смежными клетками. В полной решетке:
  $$|E_{full}| = W(H-1) + H(W-1) = 2WH - W - H$$
* **Идеальный лабиринт (Perfect Maze):**
  1. Связность: из любой клетки $(x_1, y_1)$ существует путь в любую $(x_2, y_2)$.
  2. Ацикличность: нет замкнутых петель.
  3. Фундаментальный инвариант остовного дерева:
     $$\text{Количество пробитых проходов } |E_{carved}| = |V| - 1 = W \times H - 1$$

## 2. 🌲 Алгоритмы Генерации (Spanning Tree Generation)

### 2.1. Рекурсивный бэктрекинг (Recursive Backtracker / DFS)
* **Как узнать:** Длинные извилистые коридоры, глубокие тупики, низкий коэффициент ветвления.
* **Пошаговый алгоритм:**
  1. Поместить стартовую клетку $(0, 0)$ в стек, пометить как посещенную.
  2. Пока стек не пуст, посмотреть вершину на вершине стека:
     * Если у неё есть непосещенные соседи $\to$ выбрать случайного соседа, пробить стену, пометить соседа и втолкнуть его в стек.
     * Если непосещенных соседей нет $\to$ вытолкнуть вершину из стека (backtrack).
  3. Повторять до опустошения стека.
* **Сложность:** Время $O(V)$, Память $O(V)$ (глубина стека в худшем случае равна $V$).

### 2.2. Рандомизированный алгоритм Прима (Randomized Prim's)
* **Как узнать:** Лабиринт растет «кляксой» из центра. Огромное число коротких тупиков, очень высокое ветвление.
* **Пошаговый алгоритм:**
  1. Выбрать стартовую ячейку, пометить её как часть лабиринта.
  2. Добавить все смежные с ней стены во **фронтир (список кандидатов)**.
  3. Пока список фронтира не пуст:
     * Извлечь случайную стену $(A, B)$ из фронтира за $O(1)$.
     * Если ячейка $B$ ещё не в лабиринте:
       - Пробить стену между $A$ и $B$.
       - Пометить $B$ как часть лабиринта.
       - Добавить все стены от $B$ к ее непосещенным соседям во фронтир.
* **Сложность:** Время $O(E) = O(V)$, Память $O(V)$ (размер фронтира).

### 2.3. Рандомизированный алгоритм Краскала (Randomized Kruskal's + DSU)
* **Как узнать:** Стены разрушаются равномерно по всему полю одновременно. Разрозненные островки постепенно сливаются в один лабиринт.
* **Пошаговый алгоритм:**
  1. Каждой ячейке сопоставить уникальное множество в **Disjoint Set Union (DSU)**.
  2. Собрать все внутренние перегородки и перемешать их (Fisher-Yates).
  3. Для каждого ребра $(u, v)$:
     * Проверить, лежат ли $u$ и $v$ в одном множестве: $\text{Find}(u) == \text{Find}(v)$.
     * Если множества разные $\to$ выполнить $\text{Union}(u, v)$ и снести перегородку.
     * Если множества одинаковые $\to$ оставить стену (иначе образуется цикл!).
  4. Остановиться, когда число компонент станет равным 1.
* **DSU Формулы:**
  * **Сжатие пути (Path Compression):**
    ```go
    func (d *DSU) Find(x int) int {
        if d.parent[x] != x {
            d.parent[x] = d.Find(d.parent[x])
        }
        return d.parent[x]
    }
    ```
  * **Сложность:** $O(E \cdot \alpha(V)) \approx O(V)$ практически линейное время благодаря обратной функции Аккермана $\alpha(n) \le 4$.

## 3. 🧭 Алгоритмы Поиска Пути (Pathfinding)

| Алгоритм | Структура данных | Эвристика | Гарантия кратчайшего пути | Паттерн раскрытия |
| :--- | :--- | :---: | :---: | :--- |
| **BFS** | Очередь FIFO | Нет | Да (невзвешенный граф) | Равномерная сфера (волна уровней) |
| **Dijkstra** | Min-Heap (Priority Queue) | Нет | Да (любые неотрицательные веса) | Раскрытие по изобарам стоимости $g(n)$ |
| **A\*** | Min-Heap | $h(n)$ Манхэттен | Да (если $h$ допустима) | Направленный сфокусированный эллипс/луч |

### 3.1. Эвристика Манхэттена в A*
Для сетки с 4 направлениями движения допустимая (admissible) и монотонная (consistent) эвристика:
$$h(x, y) = |x - x_{goal}| + |y - y_{goal}|$$
* **Функция приоритета:** $f(n) = g(n) + h(n)$
  * $g(n)$ — точная стоимость пути от старта до узла $n$.
  * $h(n)$ — оптимистичная оценка расстояния от $n$ до выхода.
* **Тай-брейкинг:** При равенстве $f(n)$ приоритет отдается узлу с меньшим $h(n)$ (большим $g(n)$), что предотвращает веерообразное рассеивание очереди.

| :--- | :--- | :--- | :--- | :--- |
| **DFS Backtracker** | Генерация | $O(V)$ | $O(V)$ | Длинный пробивающий луч с откатами назад |
| **Prim** | Генерация | $O(E)$ | $O(V)$ | Растущее ветвистое неоновое дерево из центра |
